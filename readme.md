# 线代辅助

一个功能强大的基于Web的线性代数学习辅助工具，专注于矩阵的初等变换操作和多项式处理，为线性代数学习提供直观、高效的实践环境。

## 快速开始

### 在线使用
[点击链接](https://awei808.github.io/Linear-Algebra-Helper/) 

### 本地运行
1. 下载或克隆项目到本地
2. 使用任意现代浏览器打开 `index.html` 文件，无需安装任何依赖，开箱即用
   - 手机、平板由于浏览器限制，建议使用在线版本

## 功能特性

### 核心功能
- **矩阵录入**：支持通过网格界面手动录入矩阵元素
- **快速导入**：通过二维数组格式快速导入矩阵数据
- **初等变换**：支持三种基本初等行变换操作
- **实时预览**：实时显示变换过程和结果
- **历史记录**：完整的变换历史记录，支持撤销/重做操作

### 矩阵操作
- **行交换**：交换矩阵的两行
- **行倍乘**：将某一行乘以一个非零常数
- **行倍加**：将某一行乘以常数加到另一行
- **多项式展开**：对矩阵中的多项式元素进行展开
- **一元多项式因式分解**：对矩阵中的一元多项式进行因式分解
- **替换矩阵元素**：灵活替换矩阵中的任意元素

### 方阵特色功能
- **计算对角线乘积**：快速计算方阵的对角线元素乘积，用于辅助行列式计算和特征值计算。
- **生成增广单位矩阵**：自动生成增广单位矩阵，用于求逆矩阵
- **生成含λ的矩阵**：创建含有λ参数的矩阵，适用于特征值计算

### 用户界面
- **响应式设计**：适配不同屏幕尺寸
- **直观操作**：点击式操作，无需记忆命令
- **状态提示**：清晰的操作指引和状态显示
- **帮助系统**：内置帮助文档，指导用户使用各项功能

## 使用指南

### 1. 录入矩阵
- 点击"录入矩阵"按钮
- 在网格中选择矩阵维度
- 输入矩阵元素值
- 点击"下一步"完成录入

### 2. 执行初等变换
1. 选择目标行/列
2. 选择变换类型（交换、倍乘、倍加）
3. 输入相关参数（如系数）
4. 选择参数行/列（适用于倍加操作）
5. 点击"执行初等变换"按钮

### 3. 高级功能
- **快速导入**：点击"导入二维数组为矩阵"按钮，输入标准二维数组格式，如：`[[1,2,3],[4,5,6]]`
- **导出矩阵**：通过"更多"菜单中的"导出矩阵为二维数组"功能，将矩阵数据复制到剪贴板
- **多项式处理**：使用"多项式展开"和"一元多项式因式分解"功能处理矩阵中的多项式元素
- **方阵操作**：利用方阵特色功能快速进行特殊矩阵操作

## 技术特点

### 前端技术
- 纯HTML/CSS/JavaScript实现
- 响应式布局设计
- 无框架依赖，轻量高效
- 模块化代码结构，易于维护和扩展

### 数学处理
- 支持分数、小数、未知数（a, b, c, d, m, n, x, y, z, λ）等复杂矩阵元素
- 自动分数化简功能
- 多项式表达式验证和处理
- **智能格式转换**：自动识别 `.2` 格式并转换为 `0.2`, 小数自动转分数，分数自动化简功能

### 状态管理
- 基于状态机的管理模式，确保操作流程的一致性
- 完整的历史记录系统，支持多步撤销/重做
- 实时状态更新和UI反馈

## 浏览器兼容性
- 支持所有现代浏览器（Chrome, Firefox, Safari, Edge等）
- 响应式设计，适配桌面和平板设备
